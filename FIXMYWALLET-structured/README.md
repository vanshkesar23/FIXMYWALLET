# FixMyWallet

FixMyWallet is a gamified personal-finance investigation experience.

## Project structure

```text
FIXMYWALLET/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── app.js
├── assets/
│   ├── images/
│   └── icons/
├── .gitignore
└── README.md
```

## Run locally

Open `index.html` in a browser, or use a local server such as VS Code Live Server.

## Notes

- The existing UI and JavaScript behavior were preserved.
- Inline CSS was moved to `css/style.css`.
- Inline JavaScript was moved to `js/app.js`.
- Asset folders are ready for future images/icons.
- This is an organization/refactor only; it does not convert the project to React or Next.js.
